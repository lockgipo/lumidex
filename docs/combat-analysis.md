# LumiDex 地圖屬性效益分析 — v0.6 初版

日期：2026-11-08。狀態：v0.6 發布版，待 iPhone Safari 實機驗收。

## 目標與實際提供的功能

- 載入現有 18 張地圖與 90 種怪物；依地圖可列出一般怪物、選擇單隻怪物或選擇包含 Leader。
- 官方怪物頁提供 HP、ATK、MATK、DEF、MDEF、FLEE、HIT、EXP、元素及重生秒數；資料存放於 `monster-stats.json`，沿用現有怪物的穩定 ID，不改動 `data.json` 與 `index.html` 內嵌資料結構。
- `combat-model.js` 為瀏覽器與 Node 通用的無依賴計算核心。
- `analyzer.html` 在本機網頁預覽：物理或魔法、原有與增加的穿透（百分點）、HIT 與增加 HIT；呈現每隻怪物各自的增益，沒有假平均。
- 選擇單隻怪物、提供確實已命中且未暴擊的單次傷害時，才提供「成功命中次數」擊殺門檻（仍不保證實戰攻擊次數）。

## 官方資料、來源與公式

- 官方怪物索引：https://www.lumivaraonline.com/wiki/monsters/
- 官方戰鬥公式：https://www.lumivaraonline.com/wiki/ 「Combat & Stats」
- 單一怪物原始頁網址保存在每個 `monster-stats.json` 項目的 `wiki`。
- 防禦減傷比例 = min(DEF 或 MDEF, 255) / 300；額外穿透百分點直接抵銷減傷，最終減傷不小於 0。分開處理 DEF/物理穿透、MDEF/魔法穿透。
- 命中率 = clamp(1 + (HIT - FLEE) × 0.0025, 0.4, 1)，只有經確認的特殊必中技能可忽略。
- 傷害變動比例 = 新防禦後傷害倍率 / 舊倍率 - 1；HIT 的命中效益為新命中率 / 舊命中率 - 1。
- 預估 N 次成功命中擊殺門檻 = ceil(HP / N) 有效傷害／次，僅理論推估，無法據此精準估算 DPS 或 EXP/hour。

## 資料維護與檢查

```sh
node scripts/sync-monster-stats.mjs --check
node scripts/sync-monster-stats.mjs --write
node --test
```

- `--check` 重新讀取官方公開頁面、核對每隻怪物的名稱與等級，不能把無法對應的資料自動合併。
- `--write` 只有全部 90 種都通過校驗才覆寫 `monster-stats.json`。
- 同步器沒有登入、沒有遊戲市場存取、不自動排程；不主動將資料傳到公開站。
- 快照不包括裝備、技能資料或完整戰鬥數據。日後官方更新需人工核對變動與重新測試。

## 已知限制及下一階段

1. 公式尚未納入實際 ATK/MATK 形成方式、加成堆疊、技能倍率、暴擊、攻速、元素倍率、SP 消耗、怪物抗性與移動／刷新時間。
2. 顯示的穿透收益和 HIT 收益都以其他條件不變為前提，不能直接當作完整掛機收益或配裝排名。
3. 沒有怪物擊殺權重，因此禁止憑怪物數量或 EXP 簡單平均來推斷整張地圖效率。
4. ATK%、暴擊傷害等屬性在公式與實測校準完成前，不加入定量排名。
5. 下一階段驗證 iPhone Safari／桌面 Chrome 的實際互動，擴充技能圖鑑與屬性標籤，再把卡片效果導入同一計算核心。
6. 公開發布範圍僅含靜態網站、官方資料快照、公式核心及必要的驗證工具；市場實驗性的被動讀取腳本保留在本機，不公開。
