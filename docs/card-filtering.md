# LumiDex v0.6.1 卡片分類與農卡反查

狀態：v0.6.1 已發布 GitHub Pages；iPhone Safari 真機視覺／手勢驗收待完成。

## 已完成

- 依現有 88 張卡片官方來源的繁中效果文字，即時計算卡片「效果分類」。僅作分類、搜尋與關聯導覽，**不產生新的戰鬥數值、不推算 DPS**。
- 分類：ATK、MATK、物理／魔法穿透、CRIT、暴擊傷害、HIT、FLEE、ASPD、基本六屬、HP/SP、DEF/MDEF、其他輔助、特殊機制。
- 特殊機制卡獨立為特殊類，避免把「條件式增益／機率觸發」錯當永久固定數值。分類的中文名稱不代表已可直接參與配裝計算。
- 篩選條件：可多選效果分類（**AND：全部符合**），並和既有文字搜尋、地圖、裝備部位、已核對來源及新增來源種類一起使用。
- 來源種類：全部／已核對怪物掉落／特殊來源／尚待核對。只有 `verifiedDrops` 才算一般怪物已核對掉落，不以同名關聯冒充掉落來源。特殊來源也不冒充怪物掉落。
- 地圖與怪物詳情增加直達「本圖／這隻怪物已確認掉落卡片」；打開卡片列表後有提示，且可取消單隻怪物限制。
- 手機版效果分類預設收合，可展開多選；結果顯示簡短效果標籤、目前套用的篩選資訊，不動原本卡片收藏、價格紀錄、語言設定的 localStorage key。

## 相容性與限制

- 主資料 `data.json`、首頁嵌入 JSON、88 卡穩定 ID、怪物／地圖關聯、收藏 key `lumidex-v1-favs` 均未調整。
- 效果標籤衍生自 `card.effect` 文字及 `card.special` 標記；若未來官方新增符號或改用不同語言，需補上分類規則及回歸測試。
- `ATK` 與 `MATK`、`DEF` 與 `MDEF` 不能錯分。特殊機制即使提及 ATK 或暴擊，也不列入固定 ATK／暴擊分類。
- 一般地圖清單顯示既有「關聯卡片」；新農卡按鈕則限定**已核對掉落**，兩者不能混稱。
- 已知 iPhone Safari 真機視覺、手勢與滾動行為仍待使用者驗收；本輪僅通過 Node 互動模擬／資料測試。嘗試 Windows Chrome/Edge 無頭瀏覽器時未能取得頁面 DOM，因此不宣稱完成瀏覽器實測。
- 本階段不重新啟動市場價錢自動掃描、不新增帳號／伺服器；已依使用者明確授權發布靜態網站更新至 GitHub Pages。
