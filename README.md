# LumiDex — Lumivara Online 繁體中文圖鑑

**v0.6.4｜非官方、免費、非商業個人使用中**

網站：https://lockgipo.github.io/lumidex/

## 功能
- **88 張卡片、90 種怪物（含 Leader）、18 張地圖**的搜尋及反查
- 88 張卡片、90 種怪物、18 張地圖均有繁中名稱與英文對照；可切換「繁中＋英文／繁中／English」
- 中文、英文及能力關鍵字搜尋：例如 `物理破防`、`Armor Pierce`、`ATK`、`DEX`
- 多關鍵字 AND 篩選、地圖篩選、卡片裝備部位篩選、怪物／卡片／地圖間交互查看
- **88 張卡片**全數補齊官方可鑲嵌裝備部位、NPC 收購價與階級；快速預覽、詳情、比較皆可看到裝備部位
- **22 張特殊技能卡**依官方卡片詳情補齊繁中機制說明：觸發條件、傷害／機率、冷卻、疊加與 PvP 限制；可用繁中效果關鍵字搜尋，詳情保留官方原名與來源連結
- 新增 **72 種怪物專屬材料**，可依 NPC 收購價排序並反查怪物、地圖與 30% 掉落率
- 材料僅保留 **NPC 收購單價、掉落率、怪物與地圖來源**，不再顯示每 100 隻預期收益
- 不離開列表的詳情面板、最多四張卡片比較與瀏覽器本地收藏
- 手機 Safari / Windows Chrome / Edge 的響應式介面

### v0.6.4：iPhone 首頁體驗優化（已發布）
- 首頁改為簡潔圖鑑標題、單排四筆資料統計、搜尋、卡片效果篩選與結果優先，減少卡片出現在首屏前的垂直捲動量。
- 右上「設定與工具」收納繁中/英文切換及地圖屬性效益分析；「篩選與排序」收納來源、可鑲嵌部位、地圖、排序及已核對來源，可查看目前使用的條件數並單鍵清除。
- 底部五個分類以同系列線條圖示表示；保留分類邏輯、88/90/18/72 資料集、收藏與全部功能，不增加網頁依賴。
- Linux Node regression + 本機 Chrome 手機寬度檢查通過；已發布 GitHub Pages，iPhone Safari 真機視覺／觸控驗收仍待進行。

### v0.6.3：手機分類篩選與首頁精簡
- 四個資料統計提至頁首，數字依實際資料集更新；移除搜尋框下方重複的六個快捷標籤，保留搜尋與桌面側邊快速入口。
- 「主屬性」可展開 STR、AGI、VIT、INT、DEX、LUK；HP/SP 與 DEF/MDEF 亦可展開並複選。同組任一符合，跨組及其他分類全部符合；特殊機制卡不當作固定增益。
- CRIT 標示為「暴擊率」。依官方 Wiki，卡片 CRIT 可計入符合 Spell Critical 規則的魔法技能；目前 88 張卡片無獨立 MCRIT 條目。
- 88 張卡片、穩定 ID、地圖/怪物關聯、收藏資料與分析器未變；手機 Safari 待實機驗收。

### v0.6.1：卡片分類及掉落反查
- 為 88 張卡片依現有文字效果建立 14 種能力／特殊機制分類，可多選 AND 篩選，並與裝備部位、地圖及文字搜尋併用。
- 增加來源篩選：已核對怪物掉落／特殊來源／來源待確認；地圖或怪物詳情可直接查看已確認掉落卡片，不會將同名關聯誤認為掉落。
- 手機版使用可收合的分類面板；顯示已套用的篩選與卡片效果標籤；原有收藏維持不變。
- 已發布於 GitHub Pages；iPhone Safari 的視覺與手勢驗收仍待實機測試。開發規格與驗收限制見 [開發紀錄](docs/card-filtering.md)。

### v0.6.2：移除卡片玩家市場行情
- 網頁不再顯示玩家市場地區、卡片最低掛賣價、7 日成交均價、行情匯入／編輯及價格排序；卡片比較也不包含行情。
- 移除不再使用的行情驗證程式與批次匯入工具；保留官方 NPC 收購價、怪物掉落資料、收藏及地圖屬性分析器。
- 不會自動刪除使用者瀏覽器原本的行情 localStorage 資料；只是停止存取及顯示。此版本已發布至 GitHub Pages。

### v0.6 地圖屬性效益分析（第一階段）
- `analyzer.html` 可選 18 張地圖、指定怪物／包含 Leader，依官方戰鬥數值比較物理／魔法穿透、HIT 提升對各怪物的理論效果。
- `monster-stats.json` 補齊 90 種怪物的 HP、DEF/MDEF、HIT/FLEE 等；`combat-model.js` 提供有測試的計算核心。
- 允許輸入選定怪物的單次實測命中傷害，估算純理論擊殺門檻，不代表實際掛機 DPS 或 EXP/h。
- 網頁分析器入口：https://lockgipo.github.io/lumidex/analyzer.html；仍需手機 Safari 實機驗收，計算限制與指令見 [地圖屬性分析規格](docs/combat-analysis.md)。

## 使用與驗證

用 Safari 或 Chrome 開啟上方網址，不需下載 HTML，不需登入。
可以嘗試 `物理破防`、`ATK`、`DEX`，再點結果查看來源與關聯資料。

## 重要資料限制
- 官方 Wiki 資料快照日期：**2026-11-08**；本版**不會自動同步**官方更新。
- 88 張卡片的裝備部位與 NPC 收購價已核對 Wiki；其中 72 張卡片可對應本站已有怪物掉落，另有 2 張特殊來源（Hollow、世界王 Terragorn）按官方資料另外標示，餘下卡片不假定有一般怪物掉落。
- **NPC 收購價不是玩家市場價**。材料單價只表示遊戲 NPC 回收金額。
- 繁中名稱以本機持有的台灣玩家 V107 詞彙為校對參考，僅挑選本站所需的 196 個名稱；原著整份詞庫、執行程式及授權資料**未加入**本儲存庫。譯名若與遊戲內最新版本不同，以遊戲與官方 Wiki 為準。
- 22 張特殊技能卡的文字機制已依 2026-11-08 官方 Wiki 頁面整理，未經所有職業實戰逐一驗證；若遊戲更新，以官方新版本為準。
- 收藏只存在使用者瀏覽器的本地儲存空間，不需帳號，不會同步其他裝置。
- 目前 `manifest.webmanifest` 只提供加入主畫面的基本資訊，尚未實作完整離線 PWA。

## 技術
無伺服器的靜態網頁。網站入口 `index.html` 含完整圖鑑資料快照；`data.json` 提供可供後續校驗與更新的索引。`card-filters.js` 提供卡片效果與掉落來源分類；`combat-model.js` 支援地圖屬性效益分析。
