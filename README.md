# LumiDex — Lumivara Online 繁體中文圖鑑

**v0.8.6｜非官方、免費、非商業個人使用中**

網站：https://lockgipo.github.io/lumidex/

## 功能
- **88 張卡片、90 種怪物（含 Leader）、18 張地圖**的搜尋及反查
- 88 張卡片、90 種怪物、18 張地圖均有繁中名稱與英文對照；可切換「繁中＋英文／繁中／English」
- 中文、英文及能力關鍵字搜尋：例如 `物理破防`、`Armor Pierce`、`ATK`、`DEX`
- 多關鍵字 AND 篩選、地圖篩選、卡片裝備部位篩選、怪物／卡片／地圖間交互查看
- **88 張卡片**全數補齊官方可鑲嵌裝備部位、NPC 收購價與階級；快速預覽、詳情、比較皆可看到裝備部位
- **22 張特殊技能卡**依官方卡片詳情補齊繁中機制說明：觸發條件、傷害／機率、冷卻、疊加與 PvP 限制；可用繁中效果關鍵字搜尋，詳情保留官方原名與來源連結
- 新增 **72 種怪物專屬材料**，可依 NPC 收購價排序並反查怪物、地圖與 30% 掉落率
- 材料僅保留 **NPC 收購單價、掉落率、怪物與地圖來源**，不再顯示每 100 隻預期收益
- 不離開列表的詳情面板、最多四張卡片比較與瀏覽器本地收藏
- 手機 Safari / Windows Chrome / Edge 的響應式介面

### v0.8.5（2026-11-10 正式發布）：簡易裝備傷害收益比較
- 新增 `damage.html` 與 `damage-model.js`，不依賴 Explorer、帳號或 Userscript。首頁工具入口優先進入簡易版；原 `tradeoff.html` 進階比較和 v0.8.4 裝備挑選器仍可使用，避免破壞既有功能。
- 選地圖／怪物、物理或魔法，以目前手動面板穿透、ATK%／MATK%、額外爆傷為基準，A／B 分別輸入相對目前穿著裝備的淨詞條變化（新減舊，可為負數）。顯示非爆擊與爆擊傷害指數、A／B 相對收益；不含 HIT、爆率、LUK、技能倍率變動、DPS／EXP/h。
- 固定 ATK／MATK 或主屬性變化屬進階估算，需提供目前面板 ATK／MATK 並自行換算等效固定攻擊差異，缺少必要基準時拒絕給出收益。
- 官方已確認 DEF／MDEF、穿透與爆擊因子；ATK% 同乘區加總與面板拆解**仍是假設**，標示待實測。面板設定只存在本機瀏覽器的 `lumidex-damage-v1`，可清除；不觸碰舊收藏或 Explorer 服務。實測操作請看 [ATK% 驗證指南](docs/atk-percent-verification.md)。

### v0.8.3（2026-11-08 正式發布）：裝備挑選器與可選套裝效果
- 已確認官方 Explorer 的公開裝備資料原始包含 `serial`（各件識別）、`template`（Bow/Sword/Cestus 等裝備代碼）、`top`（詞條代碼），但**沒有套裝名稱、職業適用或每件裝備的需求等級欄位**。角色職業 `classId` 為字串（Gipo 是 `archer`），過去版本誤判為數字而略過。
- 正式版保留必要的公開裝備欄位並修正職業代碼解析；不傳送不需要的 `finder`、貨幣與其他玩家資料。
- 候選裝備改用手機卡片清單，直顯 ATK、DEX、穿透、爆傷等詞條，同名裝備依來源位置區分；支援文字篩選、背包／倉庫來源、依能力排序、分批顯示。
- 依已確認的官方 Wiki 武器規則過濾弓箭手 Bow、劍士 Sword、法師 Rod／Staff 等；未知職業／裝備需求不假設可用或不可用。原始資料**沒有套裝歸屬**，不可自行推算套裝加成。
- **新增可選的手動套裝設定**：在裝備匯入區下方，分別設定 A／B 的套裝與件數，支援同時搭配多套。依官方 Wiki 11 種套裝自動辨識 2 件（可疊 3 層）、4 件、6 件門檻，顯示啟動效果；可一鍵複製 A 到 B。只有使用者明確勾選確認才將已知套裝加成納入條件式比較；未知 CRIT 點數不會冒充實際爆擊率，回血／SP／生存效果只展示不當作 DPS。匯入本身**仍不包含套裝歸屬**。
- **Vercel API 已更新至 v0.8.3 並發布正式站**。新版 API 只回傳公開裝備及必要的 `serial`／`template`／`top`／`classId` 等欄位；從正式網域進行的 Gipo API/CORS 整合測試通過。Safari 真機的介面與數值仍待使用者驗收。細節：[裝備挑選器與套裝說明](docs/gear-picker-v0.8.3.md)。

## 重要資料限制
- 官方 Wiki 資料快照日期：**2026-11-08**；本版**不會自動同步**官方更新。
- 88 張卡片的裝備部位與 NPC 收購價已核對 Wiki；其中 72 張卡片可對應本站已有怪物掉落，另有 2 張特殊來源（Hollow、世界王 Terragorn）按官方資料另外標示，餘下卡片不假定有一般怪物掉落。
- **NPC 收購價不是玩家市場價**。材料單價只表示遊戲 NPC 回收金額。
- 繁中名稱以本機持有的台灣玩家 V107 詞彙為校對參考，僅挑選本站所需的 196 個名稱；原著整份詞庫、執行程式及授權資料**未加入**本儲存庫。譯名若與遊戲內最新版本不同，以遊戲與官方 Wiki 為準。
- 22 張特殊技能卡的文字機制已依 2026-11-08 官方 Wiki 頁面整理，未經所有職業實戰逐一驗證；若遊戲更新，以官方新版本為準。
- 收藏只存在使用者瀏覽器的本地儲存空間，不需帳號，不會同步其他裝置。
- 目前 `manifest.webmanifest` 只提供加入主畫面的基本資訊，尚未實作完整離線 PWA。
